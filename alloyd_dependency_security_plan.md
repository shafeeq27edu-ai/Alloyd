## 3. Security Status
- **python-jose**: Unmaintained. Security risks due to lack of patches.
- **passlib**: Unmaintained. Incompatible with `bcrypt>=4.0.0` (which removed `_bcrypt` internals).
- **google-generativeai**: Deprecated by Google in favor of `google-genai`.

## 4. python-jose Assessment
- **Current Usage**: Token creation (`jwt.encode`) and validation (`jwt.decode`) in `app/core/security.py` and `app/api/deps.py`. Exception handling relies on `jose.JWTError`.
- **Recommendation**: Replace with `PyJWT`.
- **Migration**: 
  - `requirements.txt`: `-python-jose[cryptography]` `+PyJWT`
  - `security.py`: `import jwt`
  - `deps.py`: `import jwt`, replace `JWTError` with `jwt.InvalidTokenError` (or `PyJWTError`).

## 5. PyJWT Assessment
- Highly maintained, secure, standard for JWT in Python.
- API is mostly a drop-in replacement for python-jose.

## 6. Passlib Assessment
- **Current Usage**: `CryptContext(schemes=["bcrypt"], deprecated="auto")` used for hashing and verifying passwords in `security.py`.
- **Recommendation**: Remove `passlib` and use `bcrypt` directly.

## 7. bcrypt Assessment
- **Current Usage**: Backend uses `bcrypt` via `passlib`.
- **Recommendation**: Since `bcrypt` handles salting and hashing directly, we can wrap its API in `security.py`:
  ```python
  import bcrypt
  def verify_password(plain, hashed):
      return bcrypt.checkpw(plain.encode(), hashed.encode())
  def get_password_hash(password):
      return bcrypt.hashpw(password.encode(), bcrypt.gensalt()).decode()
  ```
- **Compatibility Risk**: Existing hashes generated by passlib (which wraps bcrypt) are standard bcrypt hashes and will be fully compatible with `bcrypt.checkpw()`. No user lockouts will occur.

## 8. Gemini SDK Assessment
- **Current Usage**: `import google.generativeai as genai` in `gemini_adapter.py`.
- **Recommendation**: Migrate to `google-genai` SDK.
- **Migration**:
  - `requirements.txt`: `-google-generativeai` `+google-genai`
  - API Change:
    ```python
    # OLD
    genai.configure(api_key=api_key)
    model = genai.GenerativeModel(model_id)
    response = await model.generate_content_async(contents)
    
    # NEW
    from google import genai
    client = genai.Client(api_key=api_key)
    response = await client.models.generate_content(model=model_id, contents=contents)
    ```

## 9. FastAPI / Starlette / Pydantic Assessment
- Versions are stable and secure (`fastapi==0.136.1`, `pydantic==2.13.3`). No upgrades necessary.

## 10. Database Stack Assessment
- SQLAlchemy (`2.0.51`), Alembic (`1.18.5`), asyncpg (`0.29.0`) are on secure, modern versions. No upgrades necessary.

## 11. AI Provider SDK Assessment
- **Groq**: Version 1.2.0 is recent and secure.
- **Anthropic**: Ensure a modern version (e.g. `^0.30.0` or `1.0.0+`) is installed.
- **Gemini**: Needs migration (see Section 8).

## 12. Frontend Dependency Assessment
- Next.js and React versions are modern. No critical CVEs detected in the top-level packages. UI libraries are up-to-date. No upgrades necessary.

## 13. Known Vulnerabilities
- `passlib` vulnerability/incompatibility with modern Python versions and bcrypt >= 4.
- `python-jose` lacks active maintenance for potential cryptographic vulnerabilities.

## 14. Deprecations
- `google-generativeai` is deprecated.
- `passlib` is deprecated for modern usage.
- `python-jose` is deprecated.

## 15. Compatibility Concerns
- Replacing `passlib` with raw `bcrypt` preserves database hashes.
- Replacing `python-jose` with `PyJWT` requires careful exception mapping.

## 16. Proposed Upgrades & Replacements
1. Replace `python-jose` with `PyJWT`.
2. Replace `passlib` with raw `bcrypt`.
3. Replace `google-generativeai` with `google-genai`.

## 17. P0/P1/P2 Classification
- **P0**: Replace `passlib` with `bcrypt` (Blocker for Python 3.13 / bcrypt 4.x runtime failures).
- **P0**: Replace `python-jose` with `PyJWT` (Security maintenance blocker).
- **P1**: Replace `google-generativeai` with `google-genai` (Deprecation).
- **P2**: Ensure `anthropic` client SDK is up-to-date on installation.

## 18. Migration Risks
- **Authentication**: If hash verification logic is flawed in migration, users cannot log in.
- **Tokens**: If PyJWT decode params are misconfigured, valid sessions will drop.
- **Gemini**: API response structures differ; adapter streaming parsing must be re-tested.

## 19. Required Tests
- Verify login with an existing user account.
- Verify creating a new user account.
- Verify JWT generation and protected endpoint access.
- Verify Gemini chat completion and streaming.
